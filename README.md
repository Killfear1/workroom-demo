# Workroom demo

An interactive demo of Workroom: an agent that does a task on a computer,
one allowed step at a time. You tell it what to do in plain words, it asks
before each move, and you can stop and take over at any time.

**Try it: https://killfear1.github.io/workroom-demo/**

Everything runs inside your browser. It is a full simulation: no download,
no account, and no real machine is involved. See HOW-TO-TRY-IT.md.
